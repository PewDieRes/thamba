# Codex evidence

## Orchestration disclosure

The Codex runs in this repository were orchestrated by an AI assistant
(Claude Code) on the owner's instruction, using `codex exec` with the model and
reasoning effort recorded per run. The owner does the field research,
interviews, and pilot.

## Records

- [Model log](model-log.md) records the model, reasoning effort, surface, and
  disposition for each run.
- [Mistakes caught](mistakes-caught.md) records reported Codex mistakes, how
  they were caught, and links to their fixes.
- [Stage evidence](stages/) holds links to work, checks, and human decisions
  for each stage.

The initial backfill uses the owner-supplied summaries. The date is the
backfill date because individual run timestamps were unavailable. For those
rows, “accepted” records that the output is present in the repository. Formal
review decisions were unavailable. PR or commit links are marked TODO pending
verification.
