# Coordinator dashboard

Open `/[locale]/coordinator` and sign in from the browser that requested the magic link. The dashboard displays a Stand covered by the active Coordinator membership. The Driver roster, live booking board, queue history and rides log follow the selected Stand's Town and Demo Run.

Issue an invite for an available synthetic Driver record, then share the one-time URL with **Share on WhatsApp**. Redeeming it binds the Driver's browser. Device revocation ends that binding.

Set a Driver offline or record a break, skip or walk-up to remove them from rotation. **Rejoin queue** adds them at the tail. Queue history shows the recorded reasons and the position changes they caused. **Export CSV** downloads Booking IDs, statuses, pickup times and fare amounts for the rides log. Today's Trip count uses India time.
