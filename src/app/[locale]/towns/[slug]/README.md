# Town overview

The Town catalogue shows Stands, fixed fares and the localized grievance contact. Malvan remains information-only while its licence is pending.

Choose **Try the demo** on the home page or within Demo Town. Choose **Complete a Trip** to follow the scripted Trip through completion, or **No Driver available** to see a scripted decline and an exhausted search. Starting provisions a new run for the anonymous Rider session with its own Stand and Driver. **Share Town link** copies the public overview URL so another Rider can start a run.

The simulated complaint form accepts a sample topic and stores the submission within the active Demo Run. It accepts only predefined topics. Complaints can be submitted by the Rider who started the run while it is active.
