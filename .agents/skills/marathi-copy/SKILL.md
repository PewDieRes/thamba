# Marathi and Hindi copy

Use the fixed glossary below. Keep ICU argument names, selectors, branches,
format specifiers, braces, and plural `#` tokens intact. Translate only the
literal text within messages. Keep locale keys in parity. Check button text
in its rendered form and count user-perceived characters (grapheme clusters).

of at most 14 characters, such as `पुढे जा` or `रद्द करा`. Use Western digits
(`0–9`) in visible text.
